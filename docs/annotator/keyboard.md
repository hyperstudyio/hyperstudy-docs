# Keyboard shortcuts

These keys work on the Annotator page whenever you are not typing in a text field. **?** shows a reminder of them
in the panel.

## Playing and moving

| Key | What it does |
|---|---|
| Space | Play or pause: the clip if one is selected, else the video from the playhead |
| Shift+Space | Play what is selected as a clip |
| ⌘← / ⌘→ (Ctrl on Linux) | Grow the clip by 0.1 s on that side (with Shift: 1 s) |
| ⌥⌘← / ⌥⌘→ (Ctrl+Alt on Linux) | Shrink the clip: its other end moves that way |
| L | Loop clips, or play them once |
| ← / → | The previous or next item in the selected row, played. With nothing selected, the utterances around the playhead |
| Shift+← / Shift+→ | Back or forward one second |
| , / . | The previous or next shot |
| j / k | The next or previous uncertain utterance (opens Review) |
| Esc | Let the clip go and clear the selection |
| \ | Show or hide the panel |
| ? | Show or hide the key reminders |

## Correcting

| Key | What it does |
|---|---|
| ⌘Z / Ctrl+Z | Undo the last change |
| 1–9 | On a selected utterance: the speaker is that numbered face |
| o | On a selected utterance: an off-screen voice |
| m | On a selected utterance: several people |
| u | On a selected utterance: unsure |
| x | On a selected utterance: not speech |

## Annotating

| Key | What it does |
|---|---|
| A | Annotate what is selected, or the shot under the playhead, with the current type |
| [ then ] | Mark where an annotation starts, then where it ends |
| y / n | Yes or no, for a selected yes / no annotation |
| 1–9 | The category, in the order listed, for a selected category annotation |
| Enter | Open the selected annotation's menu |
| ⌫ / Delete | Delete the selected annotation |
| ⌥ (Alt) while dragging | Place an annotation's edge without snapping |

## Menus (macOS)

| Key | What it does |
|---|---|
| ⌘O | Import a bundle |
| ⌘E | Export this video's annotations |
